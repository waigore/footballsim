# Plain English communication

All human-facing text (GitHub issues, PR titles/bodies, issue/PR comments, wiki pages) must be **plain English**:

- Short sentences and everyday words
- No agent or skill jargon in the main body
- Do not pile unexplained IDs (`REQ-*`, `RUB-*`, `DR-*`) into the main story — put those in a short agents section if needed

Optional short `## For agents` (or similar) at the **end** for machine-oriented detail (requirement IDs, file paths, checklist keys). Everything above that section stays plain English.
