# Issue comments (resolve)

Keep comments short and in plain English. Prefer links over pasting logs.

## When opening / updating a fix PR (still `todo`)

```markdown
Working on this in <PR URL>.
Evidence (in progress): https://github.com/waigore/footballsim/wiki/evidence/issue-N
```

## When marking `resolved` (after merge + all tasks done)

```markdown
Done via <merged PR URL(s)>.
Evidence: https://github.com/waigore/footballsim/wiki/evidence/issue-N
All issue tasks finished (code and any wiki follow-ups). Ready for verification.
```
